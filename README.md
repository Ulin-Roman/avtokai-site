# АвтоКай — avtokai.ru

Исходники сайта срочного выкупа автомобилей в Санкт-Петербурге и Ленинградской области. Копия получена с хостинга REG.RU **15 ноября 2026 года**. Сайт работает на PHP и MySQL/MariaDB; сборщик JavaScript не требуется.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `index.php` | Главная, посадочные страницы, формы оценки и обратного звонка, обработка фотографий и уведомления Telegram. Стили и JavaScript преимущественно находятся здесь же. |
| `admin.php` | Вход администратора, работа с заявками и редактор SEO-текстов. |
| `config.php` | Чтение закрытых настроек из переменных окружения сервера. |
| `seo_data.json` | Публичные SEO-тексты для 74 географических страниц `?spb=…`. |
| `service-pages.json` | Контент шести тематических посадочных страниц. |
| `robots.php`, `sitemap.php` | Генерация `robots.txt` и `sitemap.xml`. |
| `.htaccess` | HTTPS, маршрутизация Apache, кэширование и ограничения доступа. |
| `direct-feed.xml` | Рекламный XML-фид. |
| `font.css`, `all.min.css` и каталоги медиа | Шрифты, иконки, фотографии и видео сайта. |

В репозитории нет базы данных с заявками, учётных записей администраторов, загруженных клиентами фотографий, журналов и истории попыток входа. Публичные SEO-тексты и медиа сайта сохранены отдельно от этих данных.

## Требования

- PHP 8.x с расширениями `pdo_mysql`, `curl` и `gd`.
- MySQL/MariaDB и отдельная база данных для этой установки.
- Apache с `mod_rewrite` и поддержкой `.htaccess` для полного воспроизведения маршрутов сайта.
- Права записи для каталога `uploads/`, журнала попыток входа и SEO-файла при работе через административную панель.

## Закрытые настройки

В исходной копии реквизиты базы данных и Telegram были записаны непосредственно в PHP. В этой версии они заменены переменными окружения. **Рабочий сайт на REG.RU при импорте не изменялся.**

| Переменная | Значение |
| --- | --- |
| `AVTOKAI_DB_HOST` | Сервер БД; по умолчанию `localhost`. |
| `AVTOKAI_DB_NAME` | Имя отдельной базы данных. |
| `AVTOKAI_DB_USER` | Пользователь БД. |
| `AVTOKAI_DB_PASS` | Пароль пользователя БД. |
| `AVTOKAI_TELEGRAM_BOT_TOKEN` | Токен Telegram-бота для уведомлений. |
| `AVTOKAI_TELEGRAM_CHAT_ID` | Получатель уведомлений Telegram. |

Пример имён переменных находится в `.env.example`. PHP сам не загружает `.env`: задайте переменные в окружении PHP-процесса средствами хостинга. Для локального запуска в Bash можно создать свою игнорируемую Git копию `.env`, заполнить её и выполнить:

```bash
set -a
. ./.env
set +a
php -S 127.0.0.1:8080 -t .
```

Не используйте рабочие реквизиты для демонстрационной установки. Встроенный PHP-сервер подходит для проверки главной страницы; правила `.htaccess`, `robots.txt`, `sitemap.xml` и редиректы проверяйте на Apache.

При пустых обязательных реквизитах БД PHP отвечает `503` и не пытается подключаться от имени анонимного пользователя. При пустых настройках Telegram обращения к его API не выполняются.

## База данных и формы

`index.php` создаёт отсутствующие таблицы `orders`, `order_photos` и `admins` в уже существующей настроенной базе данных. Новую учётную запись администратора нужно создать отдельно: поле `admins.password_hash` должно содержать результат PHP `password_hash()` для выбранного пароля. Рабочие записи администратора не переносились.

Для приёма фотографий создайте доступный PHP-процессу каталог `uploads/`. Не переносите в Git его рабочее содержимое. Лимиты загрузки задавайте также в конфигурации PHP: `upload_max_filesize`, `post_max_size`, `max_file_uploads`; ограничения из `ini_set()` не заменяют серверные настройки для уже полученного запроса.

Формы отправляют `POST` в текущий URL. На настроенной серверной копии они сохраняют настоящие заявки и могут отправлять уведомления. Для проверки используйте отдельную базу данных и тестовый Telegram-чат. Отправка тестовых заявок на рабочий сайт при импорте не выполнялась.

## Публикация

Основной сайт: <https://avtokai.ru/>. `.htaccess`, canonical, sitemap и рекламный фид ориентированы на этот домен. Для размещения копии на другом домене сначала проверьте эти адреса и правила HTTPS.

В PHP-копии сохранены подключённые на рабочем сайте Яндекс Метрика и Callibri. На тестовом домене настройте отдельную аналитику или отключите её до проверки, чтобы не смешивать тестовые посещения с рабочей статистикой.

GitHub Pages не исполняет PHP. Для портфолио используется отдельно подготовленная статическая демоверсия; она не заменяет эти серверные исходники. Автоматическая публикация этой PHP-копии на REG.RU не настроена.
